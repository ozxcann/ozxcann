## Hakkımda

Merhaba — ben **Selami**. Bilişim Sistemleri ve Teknolojileri alanında uygulamalı projeler geliştiriyorum.
Web, masaüstü ve veri toplama katmanlarında uçtan uca çözümler üretmeyi seviyorum:
kimlik doğrulama, raporlama, scraping ve modern arayüzler.

Şu an üzerinde durduğum çizgi:

- **Full-stack web** — Spring Boot / Next.js ile güvenli, ölçeklenebilir uygulamalar
- **Otomasyon & veri** — Selenium / Playwright ile ürün ve katalog takibi
- **Kullanıcı deneyimi** — sade ekranlar, net iş akışları, görsel detay
